# Specifications and planning drafts

The user's 2026-10-06 direction is recorded in [plan.md](plan.md), [roadmap.md](roadmap.md), and [design.md](design.md). They distinguish current implementation, device-accepted 1.1 behavior, requested lesson families, and proposed future interfaces. The user has adopted Zaner-Bloser as the primary instructional reference for now. Handwriting Without Tears is a marketplace reference only. The runtime models still need alignment with Zaner-Bloser; selection does not establish that alignment or validate scoring.

These drafts do not make unimplemented features or educational validation accepted requirements. Historical conversation/code remains in `docs/`; device evidence and source decisions are linked there.
